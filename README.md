# 部品飾り色 外観検査Webアプリ (Part Color Inspector App)

カメラや画像から4か所の決まった位置にある部品の色を読み取り、合否（PASS / FAIL）を自動判定するWebアプリケーションです。  
外部サーバーへの通信は行わず、ブラウザ完結で動作します。

---

## 主な機能
- **画像検査**: 検査対象の画像ファイル（JPEG / PNG等）をドラッグ＆ドロップして即座に判定
- **Webカメラ動画＆リアルタイム検査**: PCやiPhoneのカメラから映像を取り込み、製品をかざすだけでリアルタイムに合否判定
- **合格音（ピンポン♪）通知**: リアルタイム検査で合格（PASS）になった瞬間、Web Audio APIによるクリアなチャイム音でお知らせ
- **他色混入防止判定**: 黒（P4）の部分に他の3色（赤、青、緑）が誤って組み付けられている場合を確実に検知して不合格（FAIL）判定
- **アコーディオン式UI**: スクロール不要で4つのポイント（P1〜P4）の状態を一画面で同時に監視可能
- **自動保存・設定引き継ぎ**: マーカー位置や基準色、許容誤差の設定をブラウザに自動保存（次回起動時や画像切り替え時も維持）
- **iPhone / スマホ対応**: 背面カメラの自動優先起動およびタッチ操作（マーカードラッグ）に対応

---

## 使い方

### 1. ブラウザで利用（ローカル）
- `index.html` をブラウザ（Chrome, Edge, Safari等）で直接開くだけで動作します。

### 2. iPhone / スマホで利用（GitHub Pages）
1. 本リポジトリの **[Settings] ➔ [Pages]** を開きます。
2. **Build and deployment** の Source で **Deploy from a branch** を選択し、Branch を **`main` / `root`** に設定して **Save** します。
3. 数分で発行される公開URL（`https://<ユーザー名>.github.io/Part-Color-Inspector-App01/`）をiPhoneのSafari等で開くと、カメラ機能を含めてそのまま利用できます。
