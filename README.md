# 部品色外観検査アプリケーション (Part Color Inspector App)

指定された4か所の配置から部品の色を読み取り、合否（PASS / FAIL）を判定するWebベースの外観検査システムです。
外部サーバーとの通信を行わない完全クライアントサイド（HTML5 / JavaScript / Canvas / Web Audio API）構成のため、工場の製造ラインや検査工程で安全かつ高速に動作します。

---

## 主な機能

1. **4点カラーマッチング検査**
   - 4つの検査マーカー（赤、緑、青、黒）の位置を直感的に配置・微調整可能。
   - サークル探索範囲内のピクセルをスキャンし、撮影角度や配置のブレを許容するロバスト色判定。

2. **黒（P4）への他色混入防止チェック**
   - 黒であるべき位置に、他のカラーパーツ（赤・青・緑）が誤って組み付けられている場合、強制的に不合格（FAIL）として検知。
   - 「赤混入」など原因を明示。

3. **入力モード切り替え（静止画像 ⇄ Webカメラ）**
   - 撮影済み画像ファイル（ドラッグ＆ドロップ）での精密検査。
   - PCのWebカメラ映像を取り込んだ**リアルタイム動画検査**に対応。

4. **合格時「ピンポン♪」チャイム音通知**
   - Webカメラでのリアルタイム検査時、製品をかざして合格（PASS）となった瞬間に「ピンポン♪」とクリアな和音チャイムが鳴り、画面を注視せずとも耳で判定結果を把握可能。

5. **スクロールレス・アコーディオンUI**
   - 4箇所の検査ポイントの状態（現在色、誤差、合否、混入警告）を一画面で同時に監視可能。

6. **検査履歴管理＆CSVエクスポート**
   - 判定結果を即座にロギングし、ワンクリックでCSVファイルとして書き出し可能。

7. **設定の自動保存・引き継ぎ**
   - マーカー座標や許容誤差、基準色などの設定値はブラウザに自動保存され、再起動後や画像の切り替え時にも維持されます。

---

## 起動方法

1. `index.html` を任意のWebブラウザ（Google Chrome, Microsoft Edge など）で開くだけで起動します。
2. カメラ検査を行う場合は、「Webカメラ」タブに切り替えて「カメラ起動」を押してください。
